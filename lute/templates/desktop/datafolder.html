Tips for syncing

  • Only use Lute on one computer at a time. Quit Lute (tray icon, Quit Lute) before switching.
  • Before opening Lute on another computer, wait until OneDrive shows the folder as synced.
  • In OneDrive, right-click the folder and choose "Always keep on this device".
  • The Windows version warns if another computer has the data open. The Docker version doesn't, so take care when using both.
